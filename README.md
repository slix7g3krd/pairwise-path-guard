# pairwise-path-guard

文件下载接口支持相对路径后，目录穿越就跟着来了：`../` 能跳出下载根目录；URL 编码和双重编码没有归一，`%2e%2e%2f` 照样生效；绝对路径直接被接受，`/etc/passwd` 能读；符号链接解析后指向根目录外；Windows 反斜杠和盘符没有处理；空字节截断让后缀校验失效；只做前缀字符串比较，`/data-evil` 也能过；Unicode 归一化后路径变形；校验和打开之间存在 TOCTOU；错误信息回显真实绝对路径；压缩包内的相对路径也没有复查。security/path_guard.py 是核心，tests/test_path_guard.py 15个红。要修的是：路径规范化；编码归一；绝对路径拒绝；符号链接解析后再校验；分隔符统一；空字节拒绝；真实路径前缀比较；Unicode 归一；打开前复核；错误脱敏；归档路径复查。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：漏洞检测与攻防；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
